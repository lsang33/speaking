# 论点展开专项训练 — 设计文档

> 日期：2026-05-24  
> 状态：待实施

## 背景

用户反馈：结构化面试练习中，**纵向扩展**（深度分析一个点）尚可，但**横向扩展**（将简单观点展开成完整表达）较弱。具体表现为：

1. 能说出观点（如"要加强监督"），但无法将其展开为完整段落
2. 语言干瘪，词汇重复，缺乏专业表达

现有模式（题目练习、词语串联、讲述模式）都在侧面帮助，但没有**直接训练"把一句话展开成一段话"**的能力。

## 核心思路

**观点直接给，用户只练"展开"这一个动作。**

不同于现有题目模式（给一道完整的题，用户自己想观点 + 展开），新模式把"想观点"和"展开论述"解耦，让用户聚焦于展开能力的刻意练习。

## 整体流程

```
首页「论点展开」按钮
      ↓
论点来源选择（三选一）：
  · 题库提取：选题 → AI 提取 2-3 个论点 → 选一个
  · 手动输入：用户自己输入一句观点
  · 随机生成：AI 生成论点（可限领域/难度）
      ↓
准备页：
  · 论点句（大字居中）
  · AI 定制的 3 条展开方向提示
  · 时长选择：60s / 90s / 120s
      ↓
倒计时 3-2-1
      ↓
答题页：
  · 论点句常驻顶部
  · 展开方向缩略提示
  · 计时器 + 录音控制
      ↓
ASR 转写 → AI 评分（一次调用，含展开示范）
      ↓
结果页：
  · 展开专项诊断（4 维度）
  · 词汇升级建议（3-5 条）
  · AI 展开示范（对比展示）
  · [重练] [换个论点]
```

## 论点来源

### 路径 1：题库提取

1. 用户从题库选一道题
2. AI 从该题提取 2-3 个核心论点（一次轻量调用）
3. 用户选一个论点
4. AI 生成该论点的 3 条展开方向（第二次调用）

提取论点的 prompt：
> 从以下面试题中提取 2-3 个核心论点，每个论点一句话（15-30字），有观点态度，不是事实陈述。输出格式：每行一个论点，不要编号。

生成展开方向的 prompt：
> 以下是面试题和选定的论点，请生成 3 条展开方向提示，每条 10-15 字，覆盖不同角度（如原因分析、案例举例、对策建议、意义升华等）。输出格式：每行一条，以"→"开头。

### 路径 2：手动输入

用户自行输入一句观点（15-30 字），直接进入准备页，AI 生成展开方向。

### 路径 3：随机生成

用户可选限定领域和难度，AI 一次调用生成论点 + 展开方向。

> 生成一个关于【{领域}】领域的论点句，难度【{难度}】，作为公务员结构化面试的展开训练素材。论点一句话（15-30字），有观点态度。同时提供 3 条展开方向提示。

领域选项：不限 / 社会治理 / 乡村振兴 / 经济发展 / 民生保障 / 生态文明 / 法治建设 / 青年成长 / 科技创新 / 文化建设

难度选项：简单（观点直白，容易举例）/ 中等（有一定抽象度）/ 困难（需多维度展开）

### 论点质量要求

- 一句话，15-30 字
- 有观点态度，不是事实陈述
- 适合展开论述，有多个可切入的角度
- 紧扣公务员面试语境

## 答题页

- 论点句常驻顶部（小字，固定定位）
- 展开方向缩略为 pills 形式在右上角可见
- 计时器居中
- 录音控制与原模式一致
- 目标时长到达时视觉提示（计时器变色），不强制停止

## 评分设计

### 专项维度

| 维度 | 考察内容 | 评分参考 |
|------|----------|----------|
| 展开完整度 | 是否从多个角度展开？每个角度深入程度？ | 覆盖 2 个方向及格，3+ 优秀 |
| 词汇丰富度 | 独特词汇量、政策术语使用、过度重复词 | 统计去重词数，标注过度重复 |
| 论证说服力 | 举例是否具体？因果是否清晰？ | 有具体案例加分，空泛说理扣分 |
| 衔接自然度 | 角度切换是否生硬？是否使用过渡句？ | "然后""还有"堆砌扣分 |

### 基础维度（沿用）

- 语速、口头禅、卡顿停顿、时长控制

### 评分 Prompt 特殊要求

- 一次 API 调用返回评分 + 展开示范（不拆分两次）
- 输出格式中包含：展开诊断、词汇升级、展开示范、评分、评分理由、鼓励、明日聚焦
- 词汇升级格式：`原文词 → 建议词 | 理由（1 句）`

## 结果页

### 与现有结果页的差异

1. 新增「展开诊断」合并卡片，包含 4 个专项维度
2. 新增「词汇升级」模块，列出具体可升级的词汇
3. 新增「展开示范」卡片，展示 AI 对同一论点的高质量展开（200-300 字）
4. 用户的原始转写和 AI 展开示范上下排列，方便对比
5. 保留现有的客观数据模块（语速、口头禅等）

### 结果页操作

- [重练]：同一个论点重新练习
- [换个论点]：返回论点来源选择
- 如果论点来自题库提取，显示「加入题库」按钮（论点本身可作为自定义题目保存）

## 数据模型

```javascript
{
  mode: 'expansion',              // 新模式标识
  argument: '论点句文本',          // 训练的论点
  argumentSource: 'topic' | 'manual' | 'random',  // 来源
  sourceTopic: '原题文本',         // 题库提取时记录原题
  sourceTopicSubtype: '综合分析',  // 原题题型
  expandDirections: ['方向1','方向2','方向3'],  // AI 展开方向
  expandDuration: 60 | 90 | 120,   // 目标时长
  // --- 复用现有字段 ---
  transcript: '',                  // ASR 转写
  duration: 0,                     // 实际时长（秒）
  evaluation: '',                  // AI 评估原文
  score: '',                       // 分数
  metrics: {},                     // 客观指标
  audioMetrics: {},                // 音频指标
  labels: null,                    // 论点展开模式不强制标签
}
```

## 实现要点

1. 论点提取和展开方向生成需要两次 API 调用，必须分别处理 loading 状态
2. 随机生成论点时的领域和难度选择器放在准备页顶部
3. 展开方向在答题页以小号 pills 常驻显示（不占太多空间）
4. 评分 prompt 包含展开示范，输出 token 量较大（maxTokens 建议 16000+）
5. 新增模式不影响现有题目模式、词语串联、讲述模式的任何逻辑

## 后续扩展（不在本阶段）

- 展开方向完成度追踪（AI 判断是否覆盖了给定方向）
- 展开能力成长曲线
- 基于历史弱项自动推荐论点难度
